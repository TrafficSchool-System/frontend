# Swish Logotyper

Denna mapp innehåller Swish-logotyper och ikoner enligt Swish varumärkesriktlinjer.

## Filer som behövs

Ladda ner följande filer från Swish officiella webbplats:

### Primär logotyp (vertikal)

- `swish-logo-primary-light.svg` - För ljus bakgrund
- `swish-logo-primary-light.png` - För ljus bakgrund (backup)
- `swish-logo-primary-dark.svg` - För mörk bakgrund
- `swish-logo-primary-dark.png` - För mörk bakgrund (backup)

### Ikon för QR-koder

- `swish-qr-icon.svg` - Ikonen för QR-kod-betalningar
- `swish-qr-icon.png` - Ikonen för QR-kod-betalningar (backup)

## Användningsriktlinjer

1. **Placering**: Logotypen ska alltid placeras på vit eller mycket ljus bakgrund
2. **Utrymme**: Se till att ha tillräckligt med whitespace runt logotypen
3. **Inte ändra**: Använd endast originalfiler, redigera aldrig designen
4. **Med andra varumärken**: Använd skiljelinje och samma storlek

## Mer information

Se Swish officiella varumärkesriktlinjer på deras webbplats.
